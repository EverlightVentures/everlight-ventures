## Universal Pre-Close Items (ALL States)

These items apply to EVERY deal regardless of state. Complete these first.

### Phase 0: Deal Intake (Day 0)

- [ ] **Justine sign-off**: State Contract Matrix reviewed, state addendum selected
- [ ] **State identified**: ____________
- [ ] **Attorney state?**: YES (OH/GA/NC) / NO (FL/MO/TX/AZ/NV)
- [ ] **Annual deal count verified** (AZ: max 5/year without license)
- [ ] **Assignment Contract Base populated** with state addendum
- [ ] **All [BRACKETED] placeholders replaced** with deal-specific values
- [ ] **Assignment fee disclosed** to all parties per state requirements
- [ ] **Original Contract copy obtained** and reviewed for anti-assignment language
- [ ] **Anti-assignment clause check**: Does Original Contract prohibit assignment? YES -> STOP, restructure as double-close / NO -> Proceed

### Phase 1: Pre-Close (Days 1-7)

- [ ] **Title search ordered** from title company / closing attorney
- [ ] **Title commitment received** and reviewed for liens, encumbrances, exceptions
- [ ] **Seller's disclosure form obtained** (per state-specific requirements)
- [ ] **Lead-based paint disclosure** completed (if property built before 1978)
- [ ] **EMD deposited** with designated escrow holder per state rules
- [ ] **EMD receipt obtained** from escrow holder
- [ ] **Inspection/due diligence period** running -- deadline: ____________
- [ ] **Property inspection ordered** (if Assignee is conducting)
- [ ] **Assignment Agreement fully executed** by Assignor and Assignee
- [ ] **Seller acknowledgment/consent obtained** (if required by contract or state)
- [ ] **All state-specific forms completed** (see state checklist below)

### Phase 2: Mid-Process (Days 7-Close)

- [ ] **Inspection/DD period expired** -- Assignee proceeding? YES / NO
- [ ] **If NO**: Process termination, handle EMD refund, forfeit DD/option fee if applicable
- [ ] **If YES**: Confirm all contingencies satisfied or waived in writing
- [ ] **Financing confirmed** (if applicable) -- commitment letter received
- [ ] **Title clear** or title objections resolved
- [ ] **Closing date confirmed** with all parties: ____________
- [ ] **Closing agent/attorney confirmed**: ____________
- [ ] **Settlement statement (HUD-1 / CD) reviewed** for accuracy
- [ ] **Assignment fee on settlement statement** -- verify correct amount
- [ ] **Wire instructions verified** via phone callback (not just email -- wire fraud prevention)

## FLORIDA (FL) -- Closing Checklist

### Pre-Close Requirements

- [ ] Title company selected and engaged: ____________
- [ ] No attorney required (optional)
- [ ] S.B. 1240 assignment disclosure signed by all parties
- [ ] Radon disclosure (Fla. Stat. 404.056(5)) provided to buyer
- [ ] Energy efficiency brochure provided
- [ ] EMD deposited with title company within 3 business days
- [ ] 15-day inspection period tracked -- deadline: ____________

### Document Checklist

- [ ] Assignment of Real Estate Purchase Agreement (with FL Addendum A)
- [ ] Original Contract (copy attached)
- [ ] S.B. 1240 Assignment Fee Disclosure (signed)
- [ ] Seller's Property Disclosure (Johnson v. Davis standard)
- [ ] Lead-Based Paint Disclosure (if pre-1978)
- [ ] Radon Gas Disclosure
- [ ] Title commitment / Title insurance binder
- [ ] Settlement statement (Closing Disclosure)
- [ ] Warranty deed or special warranty deed
- [ ] Assignment fee disbursement authorization

### Closing Day

- [ ] Closing at title company office or via mail-away
- [ ] **Who must be present**: Buyer (Assignee) and Seller -- Assignor presence optional but recommended
- [ ] All documents signed and notarized
- [ ] EMD applied to purchase price
- [ ] Assignment fee disbursed to Assignor via settlement statement
- [ ] Documentary stamp tax calculated and paid ($0.70/$100; Miami-Dade different)
- [ ] Deed and mortgage (if any) ready for recording

### Post-Close

- [ ] Deed recorded with [COUNTY] County Clerk of Court
- [ ] Recording confirmation received
- [ ] Title insurance policy issued
- [ ] Assignment fee received by Everlight -- amount: $____________
- [ ] Copies of all executed documents filed in deal folder
- [ ] Deal logged in Broker OS dashboard
- [ ] Document retention: **5 years minimum** (FL statute of limitations)

|-------|-----------|--------|
