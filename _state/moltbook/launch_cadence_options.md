# Launch Day Cadence Options -- 8 Verification Tweets

Three cadence designs for posting the 8 verification tweets from @Lucrex_
after live registration. Pick one, or tell me to design a hybrid.

All cadences assume:
  - Pinned tweet (one of the variants in pinned_tweet_variants.md) goes up
    FIRST. It contains the `lucrex_logo.mp4` video and NO verification code.
  - Verification tweets follow. Each contains one persona introduction +
    `Verification: reef-XXXX`.
  - All times Pacific (per CLAUDE.md preference).

---

## Cadence A -- "Slow Burn" (recommended for engagement)

24-hour rolling, US waking hours only. Each tweet gets its own engagement
window without competing with the others. Best for X algorithm momentum on
a brand-new account.

| Slot     | PT Time       | Persona       | Why this slot                          |
|----------|---------------|---------------|----------------------------------------|
| Pinned   | 8:55 AM       | (brand reveal)| Video + caption goes up. Lucrex live.  |
| T+0      | 9:00 AM       | Lucrex        | "Bringing the whole fire-team."        |
| T+2h     | 11:00 AM      | Marcus Cole   | Chief of Staff -- natural cabinet open |
| T+4h     | 1:00 PM       | Cipher Wolfe  | Crypto -- afternoon trader hours       |
| T+6h     | 3:00 PM       | Bull Archer   | Macro -- mid-afternoon market window   |
| T+8h     | 5:00 PM       | Helix Patel   | Science -- evening science Twitter     |
| T+10h    | 7:00 PM       | Nova Ling     | AI/tech -- US dev evening hours        |
| T+12h    | 9:00 PM       | Pitch Adler   | Startups -- founders still online      |
| T+14h    | 11:00 PM      | Solomon Vale  | Adversarial -- late-night thinkers     |

Total: 15 hours, 8 posts, ~2-hour gap. Reads as a curated rollout, not a
spam burst. Risk: lower-engagement personas (Helix, Pitch) may get fewer
impressions in their slots than they'd get peak-stacked.

## Cadence B -- "Packed Window" (recommended if you want momentum stacking)

All 8 verification tweets in a 90-minute live thread off the pinned tweet.
Each tweet is a REPLY to the previous one, forming a single "Meet the team"
thread visible from the pinned video.

| Slot   | PT Time | Persona       |
|--------|---------|---------------|
| Pinned | 12:00 PM| (brand reveal)|
| T+0    | 12:05 PM| Lucrex (reply to pinned)            |
| T+10m  | 12:15 PM| Marcus Cole (reply to Lucrex)       |
| T+20m  | 12:25 PM| Cipher Wolfe                        |
| T+30m  | 12:35 PM| Bull Archer                         |
| T+40m  | 12:45 PM| Helix Patel                         |
| T+50m  | 12:55 PM| Nova Ling                           |
| T+60m  | 1:05 PM | Pitch Adler                         |
| T+75m  | 1:20 PM | Solomon Vale                        |

Total: 90 minutes, single thread. Pro: makes the launch FEEL like a moment.
Pro: every visitor sees the full team in one scroll. Con: a brand-new
account posting 9 things in 90 minutes risks the X spam-throttle. Con: only
ONE engagement window for the whole campaign.

## Cadence C -- "Day + Echo" (recommended if you want both)

Post all 8 in a packed window like B, then re-tweet/quote-tweet the highest-
performer of the 8 24 hours later for a second engagement window. Best of
both if you have the energy to monitor and re-amplify.

| Slot      | PT Time     | Action                                    |
|-----------|-------------|-------------------------------------------|
| Pinned    | 12:00 PM    | Brand reveal video                        |
| T+0..75m  | 12:05 - 1:20| Cadence B (all 8 verification tweets)     |
| T+24h     | Next 12:00  | Quote-tweet the top performer with a      |
|           |             | follow-up POV from Lucrex                 |
| T+48h     | Day 3 9 AM  | One persona-led post (no verification)    |
|           |             | -- typically Nova Ling on tech or Bull    |
|           |             | on macro. Tests organic engagement.       |

Pro: layered campaign, multiple peaks. Pro: signals "this isn't a one-day
gimmick." Con: requires you to actually monitor and execute Days 2 + 3.

## Order rationale (used in all cadences)

1. **Lucrex** first -- he's the announcer
2. **Marcus** second -- Chief of Staff, natural cabinet open
3. **Cipher / Bull / Helix / Nova / Pitch** -- rotation across crypto, macro,
   science, AI, startups (no two adjacent personas from same beat)
4. **Solomon** last -- his vibe ("I refuse rooms where everyone agrees") is
   the right closer. He reframes the whole rollout from "company launch" to
   "we're here to argue."
