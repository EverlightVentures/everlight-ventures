MCP HTTP Bridge -- Tool Catalog

Every tool callable from cron / Workers / scripts via POST http://127.0.0.1:2701/tool/{service}/{tool_name}. Same Python dispatchers as the stdio MCP path used by Claude Code.

broker (23 tools)

scout_hacker_news
Scrape Hacker News 'Show HN' posts via public Algolia API. No auth needed. Returns AI/SaaS relevant products as potential offers.
scout_product_hunt_rss
Scrape Product Hunt newest posts via public RSS feed. No API token needed. Returns products as potential offers.
scout_indiehackers_rss
Scrape IndieHackers RSS feed for new SaaS/tool launches. No auth needed.
scout_github_trending
Scrape GitHub trending repos (public page) for dev tools and SaaS projects.
scout_devto
Search DEV.to public API for SaaS/AI/startup articles and product launches. No auth needed.
web_scrape_public
Fetch and extract text from any public URL. For scouting product pages, blog posts, company info.
broker_ingest_offer
Add a seller's product/service to the Broker OS offer catalog via Django API.
broker_ingest_lead
Add a buyer lead to the Broker OS pipeline via Django API.
broker_run_matching
Run the AI matching engine to pair offers with leads. Returns scored matches.
broker_approve_match
Approve a match and create a deal with specified value.
broker_close_deal
Close a deal as won or lost.
broker_status
Get full Broker OS pipeline status: offers, leads, matches, deals, commissions.
broker_commission_report
Get commission summary: earned, pending, paid, unpaid balance.
email_send
Send an email via configured SMTP. Tracks warm-up limits. Requires SMTP env vars.
email_warmup_status
Check email sending limits and warm-up progress for the configured domain.
email_draft_outreach
Generate a personalized outreach email draft (seller intro or buyer intro). Does NOT send.
generate_finder_agreement
Generate a finder fee agreement template for a specific deal. Outputs markdown.
scheduler_add_job
Schedule a recurring broker pipeline job (ingest, match, report).
scheduler_list_jobs
List all scheduled broker pipeline jobs.
scheduler_remove_job
Remove a scheduled job by name.
scheduler_install_crontab
Write all enabled jobs to the system crontab. Makes schedules persistent.
broker_kpi_snapshot
Generate a full KPI snapshot: funnel metrics, conversion rates, revenue forecast.
bulk_scout_all_sources
Run all scouts (HN, Reddit, GitHub trending, IndieHackers) in one call. Returns combined results.

blinko_ai_query

blinko_ingest_note
