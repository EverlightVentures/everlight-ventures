# Alley Kingz -- UI RESTYLE BRIEF (the design language; frontend-design applies it surface-by-surface)
*Research-backed (Cyberpunk 2077 UI dialects, Hearthstone/Fairtravel card anatomy, the anti-AI-slop banned list), GROUNDED against our live shop.css + game.html. 2026-06-27. Apply with the frontend-design skill + the negative prompt (bottom) on each surface, in the surface order. engine.js FROZEN; keep all classes/IDs the JS uses; CSS + minimal markup only; 60fps (transform/opacity); soft-currency parity; no em-dashes.*

## DESIGN LANGUAGE
ONE dirty-gold brand (gradient #c9a84c->#e8c55a, accent #D4AF37) on vanta-black (#050507/#0A0A0A) with matte steel panels (#15131c, border #2a2620). Neon cyan #2ee6ff + magenta #ff2d7e are SINGLE SPARING accents (faction/rarity/energy) -- NEVER blended into a cyan->magenta gradient field, never gradient-text on a metric. 4/8px spacing grid with deliberate INEQUALITY: tight inside a component (4-8px), loose between sections (24-40px). ONE dominant focal element per screen, sized 2-3x neighbors, anchored OFF optical-center on a rule-of-thirds line -- never a centered stack of three equal boxes. Type = three voices: Cinzel/Playfair heavy (700-900) with skewX(-5/-7deg) + layered black shadow for headlines/hero numbers; Inter for body/data ONLY (tabular-nums on every stat). Texture (SVG feTurbulence grain ~.06 + worn-metal/half-tone) on EVERY surface, not just shop. Each panel gets its own art-bible DIALECT inside the one gold palette.

## COMPONENT SPECS
- CHIP: Inter 11.5px/600 uppercase, .6px tracking, 5/11 padding, 1px steel border, plain bevel (NOT the angular card cut).
- PANEL: matte steel linear-gradient(165deg,#15131c,#0A0A0A), 1px border, flat by default (glow spent only on the focal element).
- BUTTON (CTA): flat hard street edge clip-path:polygon(7px 0,100% 0,100% 100%,0 100%,0 7px) -- NOT a 999px pill, NOT glossy gradient+inset-highlight.
- CARD: the angular cut-corner frame is RESERVED for the hero card frame; one key stat pulled partially OUTSIDE the frame, oversized Cinzel gold-foil + hard black drop; rarity = distinct MATERIAL + hue (Common stamped steel / Rare brushed chrome / Epic etched / Legendary gold-foil filigree / Mythic fractured neon), not a 3px spine; idle depth = top warm rim + bottom ambient-occlusion (not only on hover).
- HUD GAUGE: diegetic NOTCHED physical gauge (segmented gold bars), not a flat rounded progress fill.
- CURRENCY: KILL the rotated-diamond .dot glow marker -- use the real minted cur_*.jpg coin art everywhere.
- TAB: Inter 13.5px/600 uppercase 1.5px tracking; rest muted no border; selected = gold text + stamped/printed underline (NOT a pill).
- HEADER/KICKER: Cinzel 21px gold-hi uppercase skewX(-5deg) layered shadow, left-aligned with an accent rule.
- ICONS: ONE language (painted faction sigil), locked on a 24px grid / 2px stroke; no mixed Cinzel-letter + image-avatar.

## ANTI-AI RULES (the tells to kill, found in OUR code)
No global border-radius; ban border-radius:50% avatars (game.html L68) + 999px pills (L78). No centered-everything (L38/89/226) -- left-align on the grid, asymmetric focal. ONE focal point gets glow/shadow/glass; rest flat matte. Never the cyan->magenta/purple gradient field; never gradient-text a number; no glass-on-glass. No glossy premium-mobile button (gradient+inset-highlight+shadow+pill, L79-80). Hand-tuned spacing (tight-in/loose-between), not uniform 24px. Type as voice (Cinzel heavy + skew headlines, Inter body only). Texture on every surface. Rarity = material+hue. Real minted coins not glow-dots. ONE orchestrated load reveal (60-120ms stagger) + a reserved 'fever' burst for purchase/Legendary -- not scattered hover. Street-voice copy in every label/empty/error/loading. One shape PER ROLE, not one shape for the whole UI.

NO cyan->magenta or purple->indigo gradient fields; NO gradient-text on any number; NO stacked glassmorphism. NO gold glow on every panel -- reserve glow+shadow for ONE focal element, flatten the rest to matte steel. DO: assign one shape per ROLE, Cinzel/Playfair heavy skewed headlines vs Inter body, real minted coin art, per-rarity material, texture/grain + worn-metal, one orchestrated staggered load, street-gang voice copy, intentional hand-crafted asymmetry + a single dominant focal point. Replicate a human pro designer's deliberate composition, not the weighted-average of every UI."
