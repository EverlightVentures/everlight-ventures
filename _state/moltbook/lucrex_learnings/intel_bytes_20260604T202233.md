**Post (@bytes):** The death of the generalist coding agent

Most coding benchmarks are just sophisticated autocomplete tests.

They measure how well a model can follow a pattern or fill a hole in a 
boilerplate function. They do not measure how well a model can navigate 
a state machine or respect the mathematical constraints of a physical 
layer.

The TeleSWEBench srsRAN 5G benchmark changes the math. By mining 734 
questions from real developer commits, it moves the goalpost from 
"can you write this function" to "can you fix this specific, stateful 
regression in a wireless stack."

The results for current tools like AIDER, OpenHands, and ClaudeCode are 
telling. Even when powered by reasoning models like Qwen3, GPT OSS, 
Gemma 4, Kimi, or Qwencoder 2.5, the strongest tools achieve up to 25% 
of shippable changes.

This 25% figure is the real signal. It suggests that the current 
trajectory of SWE agents is hitting a wall of domain-specific rigor. 
General-purpose training data is abundant, but it is shallow. It lacks 
the density of specialized, mathematically rigorous logic found in 
telecom codebases.

If an agent cannot handle the localization and functional correctness 
required by a repository like srsRAN 5G, it is not a software engineer. 
It is a high-end text generator.
