# Deal Lifecycle SOP -- the standard checklist (TN / revamp system)
*Start a lead -> work a lead -> close the sale. Every step maps to a component, a gate, and the brain.*
*Proven end to end by `scripts/wholesale_sim_e2e.py` (local dry-run, 12/12 stages pass).*

## Cross-cutting rules (apply at EVERY step)
- All outbound goes through `branded_mailer.send_branded_email()` (gold template + footer + persona alias). Never raw Resend.
- Sender identity + CAN-SPAM address from `config/sender_identity.json`. No deliverable address = sends PAUSE.
- Every send passes the gate chain: eradication/opt-out -> TN-lockdown -> CAN-SPAM -> resend_budget -> HALT.
- Every message in/out is recorded to `conversation_memory` (the relationship brain).
- Every state change advances `pipeline_phase_manager` (the conductor).
- Replies generated by `llm_compose` (persona voice + memory + market intel + brand). Invent nothing.
- Any error -> flagged, fixed, and remembered (Blinko note). Self-healing watchers (it_triage) on failure.

## A. START A LEAD
1. [ ] **Source** -- Shelby assessor parcel -> `tn_deal_tracker` (owner name + property). Dedupe. Buy-box filter (SFR, Memphis, band; no vacant/commercial).
2. [ ] **Enrich** -- skip-trace for EMAIL only (digital-only, no mail) via `hermes_harness` / `email_discovery`, gated. Status: sourced -> enriched.
3. [ ] **Qualify** -- offer math (70% rule: MAO = 0.70 x ARV - repairs). Stamp buyer match (Chris @ Mid-South). Phase: enriched.

## B. WORK A LEAD
4. [ ] **Outreach (Piper)** -- `llm_compose("piper_reeves", ctx)` warm touch-1, branded send. Record(out). Phase: contacted.
5. [ ] **Follow-up cadence** -- conductor sweep: touches at day 3/7/11/14, max 5, then 90-day rest. Silent != forgotten.
6. [ ] **Reply caught** -- `inbox_router` matches sender against the contacted registry (the signifier) -> labels to agent folder -> `conversation_memory.record(in)`. Phase: engaged.
7. [ ] **Negotiate (Henry)** -- `llm_compose("henry_hammond", ctx)` presents the cash number with the math, handles objections, rounds to agreed price. Phase: negotiating -> under_contract.

## C. CLOSE THE SALE
8. [ ] **Contract (Marvin)** -- `contract_renderer.render_psa(meta, g)` = TN SB909 PSA with equitable-interest block + assignment-fee disclosure (fee shown on settlement statement). REQUIRED meta: `final_to_seller`. Phase: under_contract.
9. [ ] **Seller signs** -- e-sign (Documenso). Title firm (Mid-South Title) RESPA-clean confirmed.
10. [ ] **Disposition (Marvin -> Chris)** -- `llm_compose("marvin_cohen", ctx)` pitch the contracted deal at the assignment price. Phase: buyer_matched -> assigning.
11. [ ] **Buyer signs assignment** -- Chris executes the assignment agreement.
12. [ ] **Close + payout** -- settlement; assignment fee (spread) = operator payout, shown as a settlement-statement line item per SB909. Phase: closing -> closed. Log the win; the brain remembers the whole relationship.

## Gating before the FIRST live send (the unblock checklist)
- [ ] CAN-SPAM deliverable address set (PO box / registered agent) in `sender_identity.json`.
- [ ] Email yield: browser-use key (Hermes) or e5 Chromium so leads have emails.
- [ ] HALT lift: clear the 6-box Streubel checklist + operator greenlight. Streubel stays eradicated regardless.
- [ ] phone_imap_poller hardened so it never auto-creates junk leads (task #13).

*The drafts auto-arm on every reply (gated). The instant the unblock checklist clears, they fire.*
