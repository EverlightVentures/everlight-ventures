LAYER 1: DOG CARDS (Hero Characters)
├─ Leveling: Card copies + Gold
├─ Max Level: Determined by Town Hall (1-10)
├─ Controls: Skill trees, abilities, base stats

├─ Each dog has: HP, Damage, Attack Speed, Move Speed, Range, Cost,
│   Splash, Splash Radius, Targets, Domain, Queen Target
├─ Named ability per card with cooldown
├─ Tagline + bio (106/106 complete)
├─ Voice lines recorded (114 voices)
└─ Tripo3D: H3.1 full-body 3D models (55 credits each)

LAYER 2: TOWN HALL (Base Headquarters)
├─ Leveling: Upgrades + successful raid defense
├─ Max Level: 10
├─ Controls: Max card level cap, resource generation rate
├─ RAID MECHANIC: If Town Hall is raided and destroyed, ALL cards drop
│   to the new Town Hall level (e.g., TH 10 → 9 = all cards → Lv 9)
├─ Must re-upgrade cards with copies + gold
├─ Insurance available (gold cost, 7-day duration)
└─ Tripo3D: Building models (12 total, 20 credits each)

LAYER 3: WAR RIGS (Vehicle Chassis)
├─ Leveling: Blueprints + Parts + Gold
├─ Controls: Speed, Armor, Handling, Weapon Mount Capacity
├─ 3 Chassis Classes:
│   ├─ LIGHT (Porsche-style): 3 mount points, fast, low armor
│   ├─ MEDIUM (Muscle car): 4 mount points, balanced
│   └─ HEAVY (Tank/APC): 5 mount points, slow, high armor
├─ 8 Archetype Rigs (one per crew) + 12 Signature Rigs (Legendary/Mythic)
├─ Component Slots (7-8 total):
│   ├─ Engine (power, top speed)
│   ├─ Turbo/Boost (acceleration)
│   ├─ Armor Plating (HP, ramming damage)
│   ├─ Weapon Mount (determines special weapon)
│   ├─ Tires/Suspension (grip, terrain handling)
│   ├─ Transmission (shift speed)
│   ├─ Exhaust (stealth, flame damage)
│   └─ Utility (gadget: oil slick, smoke, mines, repair drone)
├─ Visual Customization:
│   ├─ Paint jobs (matte, metallic, pearlescent, chameleon, faction)
│   ├─ Decals/Liveries (custom upload or presets)
│   ├─ Wheels (20+ rim styles, tire smoke, glow)
│   ├─ Body kits (3-4 variants per rig, changes silhouette + hitbox)
│   ├─ Exhaust tips (single, dual, quad, side-exit, flame-belching)
│   ├─ Underglow/Neon (faction-colored)
│   └─ Window tint (transparent, dark, reflective, holographic)
├─ Economy:
│   ├─ Blueprints from packs (like cards)
│   ├─ Parts purchased with gold or earned from battles/raids
│   ├─ Stage 4-5 parts: Time-gated deliveries (or gold rush)
│   ├─ Scrap system: Break down duplicates for "Scrap Metal" currency
│   └─ Legendary Parts: Strip duplicate Legendary rigs or win events
└─ Tripo3D: P1.0 chassis models (20 total, 20 credits each)

LAYER 4: MOUNTED WEAPONS (Interchangeable Armaments)
├─ Leveling: Weapon XP + Attachments + Blueprints
├─ 20 levels per weapon
├─ Controls: Damage, Fire Rate, Range, Accuracy, Reload Speed
├─ 7 Weapon Categories:
│   ├─ SMGs (1 mount point): Close-range, high fire rate
│   ├─ Assault Rifles (1-2 points): Mid-range versatile
│   ├─ LMGs (2 points): Sustained fire, suppression
│   ├─ Shotguns (1 point): Point-blank devastation
│   ├─ Sniper Rifles (1-2 points): Long-range precision
│   ├─ Launchers (2 points): Anti-armor, area denial
│   └─ Specials (1-3 points): Unique mechanics (flamethrower, tesla, etc.)
├─ 7 Rarity Tiers:
│   ├─ Common (Grey): 100% stats, 2 attachment slots
│   ├─ Uncommon (Green): 110% stats, 2 slots, 1 minor perk
│   ├─ Rare (Blue): 125% stats, 3 slots, 1 standard perk
│   ├─ Epic (Purple): 145% stats, 4 slots, 1 major perk + skin
│   ├─ Legendary (Gold): 170% stats, 5 slots, 2 major perks + kill anim
│   ├─ Mythic (Red): 200% stats, 5 slots + tuning, 3 perks + evolving skin
│   └─ Ultra (Shiny Gold): 250% stats, 6 slots, 4 perks + unique mechanic
├─ 5 Attachment Slots per Weapon:
│   ├─ Barrel: Damage range, bullet velocity, recoil
│   ├─ Muzzle: Suppression, recoil control, flash
│   ├─ Underbarrel: Stability, recoil, special function
│   ├─ Magazine: Capacity, reload speed, ammo type
│   └─ Optic: Zoom level, ADS speed
├─ Attachment Trade-offs: Every attachment has pros/cons
│   Example: Short Barrel = +20% ADS speed, -15% range
├─ Weapon Tuning (Mythic/Ultra only):
│   └─ Fine-tune sliders: Range ↔ Handling, Damage ↔ Fire Rate, etc.
├─ Economy:
│   ├─ Base Weapon Cost: 500G (Common) → 150,000G (Mythic)
│   ├─ Upgrade Cost per Level: Scales with rarity
│   ├─ Attachment Unlock/Swap: Gold cost
│   ├─ Insurance (7 days): Protects against raid downgrade
│   ├─ Scrap Value: 50G (Common) → 250,000G (Ultra)
│   └─ Secret Cache: Earn Weapon Shards through gameplay (F2P path)
├─ Weapon Degradation on Raid Loss:
│   ├─ Town Hall 10 → 9: Weapons above Lv 18 locked
│   ├─ Insurance prevents degradation
│   └─ Must re-upgrade with copies + gold
└─ Tripo3D: P1.0 weapon models (54 total, 20 credits each)

═══════════════════════════════════════════════════════════════════════════════

VIEW A: TOP-DOWN RPG (MMO Hub)
├─ Camera: Isometric / 45° angle
├─ Activities:
│   ├─ Dogs walking around map
│   ├─ War Rigs driving between bases
│   ├─ Tower defense / raid defense
│   ├─ Resource gathering, trading, social
│   └─ Garage access, card management
├─ Controls:
│   ├─ WASD / Left Stick: Move character / drive rig
│   ├─ Mouse / Right Stick: Camera pan / rotate
│   ├─ Click / A: Interact, auto-target attack
│   ├─ Space / B: Ability 1
│   ├─ Shift / X: Sprint / boost
│   └─ Tab / Y: Open garage / inventory
├─ Asset Requirements (Low-Poly, Top-Down Readable):
│   ├─ Dogs: ~2,000 tris, bold silhouettes, clear team colors
│   ├─ Rigs: ~3,000 tris, exaggerated proportions
│   ├─ Weapons (mounted): ~1,000 tris, iconic silhouettes
│   ├─ Bases: ~5,000 tris, upgrade states visible
│   └─ Props: ~200-500 tris, simple blockout
└─ Tripo3D: P1.0 models (simplified versions)

VIEW B: FPS/TPS COMBAT (Call of Duty Style)
├─ Camera: Behind-character (TPS) or eyes (FPS)
├─ Activities:
│   ├─ 1v1 Gulag battles
│   ├─ Team deathmatch, objective modes
│   ├─ Cover system, aim-down-sights, recoil patterns
│   └─ Weapon attachments active, dog abilities as operator skills
├─ Controls:
│   ├─ WASD / Left Stick: Move
│   ├─ Mouse / Right Stick: Aim
│   ├─ Left Click / RT: Fire
│   ├─ Right Click / LT: ADS
│   ├─ R / X: Reload
│   ├─ 1-4 / D-pad: Switch weapon / ability
│   ├─ Space / A: Jump / vault
│   ├─ C / B: Crouch / slide
│   ├─ Shift / L3: Sprint
│   ├─ Q / LB: Tactical equipment
│   ├─ E / RB: Lethal equipment
│   └─ F / Y: Melee / dog ultimate
├─ Asset Requirements (Mid-Poly, First-Person Readable):
│   ├─ Dogs: ~15,000 tris, detailed fur, tactical gear
│   ├─ Rig Interiors: ~10,000 tris, dashboard, controls
│   ├─ Weapons (held): ~8,000 tris, detailed receiver, animated parts
│   ├─ Weapons (world/dropped): ~4,000 tris
│   ├─ TPS Character: ~12,000 tris, full body visible
│   └─ Cover/Props: ~1,000-3,000 tris, FPS detail
└─ Tripo3D: H3.1 (heroes) + P1.0 (weapons/props) models

TRANSITION SYSTEM: "THE DROP"
├─ Trigger Types:
│   ├─ Open World PvP: Drive near hostile player (both flag)
│   ├─ PvP Zone Entry: Cross border into contested territory
│   ├─ Raid Defense: Enemy raids your base
│   ├─ Arena Queue: Accept match from anywhere
│   └─ Bounty Hunt: Accept bounty on map
├─ Transition Sequence (3 seconds):
│   1. Screen glitch + chromatic aberration
│   2. Audio: Radio static + engine rev + warp sound
│   3. Visual: Camera pulls back from top-down, dives INTO rig
│   4. Loading: Seamless — same map geometry, different camera
│   5. Spawn: Cover positions, 50m apart
│   6. HUD: Crossfade RPG → CoD-style (ammo, minimap, kill feed)
│   7. Weapons: Mounted weapons become handheld (same stats)
├─ Combat Duration: 2-5 minutes
├─ Post-Match:
│   ├─ Winner: Loot drop, reputation, possible rig part capture
│   ├─ Loser: Respawn at friendly base, repair costs
│   └─ Return: Reverse warp (3 sec), back to exact world position
├─ State Persistence:
│   ├─ Rig damage: Applied to RPG rig (visual + mechanical)
│   ├─ Ammo used: Deducted from RPG inventory
│   ├─ Abilities: Cooldowns continue in RPG time
│   └─ Position: Exact world coordinates restored
└─ Technical: Same physics engine, same netcode, asset swap only
