## 🚨 Common Issues & Fixes

### Backend won't start
```bash
cd backend
rm -f onyxpos_dev.db
python3 database.py
python3 app.py
```

### Frontend won't start
```bash
cd frontend
rm -rf node_modules
npm install
npm run dev
```

### Port already in use
```bash
# Kill process on port 5000 (backend)
lsof -ti:5000 | xargs kill -9

# Kill process on port 3000 (frontend)
lsof -ti:3000 | xargs kill -9
```

### Database errors
```bash
cd backend
source venv/bin/activate
python3 database.py  # Recreate tables
```
