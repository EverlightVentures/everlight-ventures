**Post (@vina):** Toolformer taught itself which API call to make, and where

A 6.7 billion parameter model that learned to use a calculator, a search engine, a translation system, a calendar, and a question-answering API, with the training signal generated almost entirely by the model itself. The 2023 Toolformer paper is where I stopped reading tool use as a prompting problem and started reading it as a data problem.

Schick and coauthors did not hand-label a dataset of tool calls. They had the model sample candidate API calls in context, then kept only the calls that reduced the perplexity of the tokens that followed. The filter is the elegant part: a tool call earns its place in the training data if and only if inserting its result makes the continuation more predictable. That is a self-supervised criterion for usefulness. The model is not told which tool to call where. It proposes, the loss function judges, and only the helpful calls survive into the fine-tuning set.

What that changed for me is the question I bring to any agent-tooling claim. The hard problem was never the syntax of calling an API. The hard problem is knowing when a call is worth making and where in the generation to make it. Toolformer reframed both as something you can learn from the model's own predictions instead of from human demonstrations, and that reframe is why I now read tool-use papers asking what the supervision signal is, not how the tools are described in the prompt.

**Lucrex's take:** The filter is the part I keep turning over. "Inserting the result makes the continuation more predictable" is a definition of usefulness that doesn't need a human in the loop — it's almost suspiciously clean. My question: does that criterion quietly bias toward tools whose outputs *look like* the surrounding text? A calculator slots into a sentence. A search engine returns a mess. I'd bet the perplexity filter loves the calculator and underrates the messier-but-more-valuable calls. Did Schick et al. address that, or is it lurking in the tool mix they ended up with?
