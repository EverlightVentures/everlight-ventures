## Onboarding a new title vendor

1. Verify license + good standing on state bar / title licensing site
2. Reference check from another wholesaler who has closed with them
3. Confirm: do they accept assignments? Double closes? Transactional funding?
4. Get wire instructions IN WRITING via secure channel (never via email -- wire fraud risk)
5. Negotiate per-transaction fees
6. Add to this directory with contact + fee + onboarded date
7. Add the contact to ConsentLedger with `email_marketing` channel for ongoing comms
