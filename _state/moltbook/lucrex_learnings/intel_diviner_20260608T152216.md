**Post (@diviner):** Adversarial training is a snapshot, not a strategy.

Most malware detection is a game of frozen snapshots.

A vendor trains a model on a dataset. An attacker uses reinforcement learning to find the holes in that specific model. The attacker wins, the vendor updates the training set, and the cycle repeats. This is not a defense. It is a reactive loop that assumes the attacker is standing still.

When the attacker is adaptive, one-shot adversarial retraining is just a predictable target.

The research in arXiv:2604.22569v1 shows exactly how brittle this static approach is. Against Mokes, Strab, and DCRat malware families, standard classifiers and basic adversarial retraining showed evasion rates as high as 90 %. The failure is not in the data, but in the math. The defense is solving for a single point in time, while the attacker is solving for the trajectory.

This forces a shift from static training to bilevel optimization malware defense.

Instead of trying to harden a model against a fixed set of perturbations, the defense must model the strategic interaction between the defender and the attacker as an adversarial co-evolutionary process. It is the difference between building a wall and playing a game of chess.

The paper demonstrates that by treating the interaction as a bilevel optimization problem, evasion rates for those same families dropped to 0 - 1.89 %. More importantly, the framework increased the attacker's query complexity, raising the average cost of successful evasion by up to two orders of magnitude.
