# THE DEALER DROPS -- daily 5-second TikTok system for $BCARDD
Base asset: `01_Media/launch/bcardi_nft_dealer.mp4` (official AI dealer video).
One clip/day, same clip to TikTok + IG Reels + YT Shorts (3 surfaces, one render).
Goal funnel: scroll-stop -> profile -> bio -> Back Room (t.me/b_card_d) + pump.fun.

## FORMAT DNA (every clip, no exceptions)
- 9:16 vertical, 3-5 seconds, dealer mp4 as the base footage
- Frame 1 IS the hook (no intros, no logos first -- the dog dealing, instantly)
- ONE text overlay, big, top third (CapCut default bold or serif)
- End beat (last 0.5s): "In DOGO we trust." small gold text
- Caption formula: one line + $BCARDD + "back room in bio" + 3-5 tags
- Tags rotation: #memecoin #solana #dogsoftiktok #crypto #dogo (swap 1-2 daily)
- Bio (set once): "A real Dogo Argentino with his own coin + game \U0001F436\U0001F0CF
  the back room: t.me/b_card_d | game: alleykingz.online"
- NEVER: investment/profit/moon language. The dog, the cards, the vibe. That's it.

## PRODUCTION (5 min/day, phone only)
1. CapCut: import dealer mp4 -> trim to the 3-5s beat the concept calls for
2. Add the day's text overlay + end beat text
3. Add trending sound, LOW volume under the clip (sounds = distribution on TikTok)
4. Export 1080p -> post to TikTok, then same file to Reels + Shorts
5. Reply to every comment with dog energy (comments = the algorithm's fuel)
